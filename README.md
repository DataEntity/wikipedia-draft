# 中文维基条目维护草稿库

本地起草、校对与版本回溯用的工作仓库，面向[中文维基百科](https://zh.wikipedia.org/)条目维护（非线上正式编辑环境）。

## 用途

- 在投稿或保存维基编辑前，离线整理导言、情节、分析与脚注
- 用 Git 保留修改历史，便于对照与回退
- 以 **一个仓库 + 多 worktree** 并行维护不同条目

## 分支约定

| 分支 | 含义 |
| --- | --- |
| `main` | 仓库主干：说明文档、共用约定；不放单一条目的正文草稿 |
| `zh/<短名>` | 某一中文条目的工作分支（由 worktree 检出） |

示例：爱伦·坡《厄舍府的崩塌》对应分支 `zh/esher`。

## 条目工作区建议结构

每个条目分支 / worktree 内可自行约定，常见做法：

```text
zh.wiki          # 条目 wikitext 草稿
.md / notes/     # 来源核对、译名与待办笔记
```

正式发布仍通过维基百科网站或账号完成；本仓库只保存本地草稿与考证过程。

## Worktree 示例

在仓库根目录：

```powershell
git worktree add ..\usher-zh zh/esher
```

之后在对应目录编辑该条目即可，与 `main` 互不干扰。
